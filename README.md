# Randomness-project
Proyecto de randomness en la clase de Análisis y Diseño de algoritmos
Genera 160,000 números aleatorios a partir del ruido de un video del patio.

Se necesita tener instalado numpy y opencv.

## Instalación

hashlib ya viene incluido con Python, así que no se instala. Las otras librerías se instalan con:
pip install numpy opencv-python
